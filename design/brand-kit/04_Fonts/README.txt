VOLTOSHARE EDITABLE TEXT

Install Liberation Sans Regular, Bold, Italic and Bold Italic from this folder
before editing the presentation. The website reference self-hosts these files.

Liberation Sans is an Arial-compatible companion for editable text. The
original editable font in the supplied raster brand images is not known.
The logo remains artwork and does not depend on an installed font.

Font use is subject to the bundled SIL Open Font License notices in LICENSE.txt.
Retain those notices when redistributing the fonts.

Official project: https://github.com/liberationfonts/liberation-fonts
