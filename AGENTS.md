# VoltoShare project instructions

## Mandatory design baseline

For every VoltoShare visual-design or branded-content task in this project—website, web app, slides, documents, diagrams, logos, icons or other project deliverables—read and apply:

[`.agents/skills/voltoshare-design/SKILL.md`](.agents/skills/voltoshare-design/SKILL.md)

Do this automatically; Mathis should not have to request the skill again. Read the skill before designing or changing a design, and follow its source references for that artifact. Later explicit user decisions take precedence and should be documented. Purely operational work with no design impact need not load the whole brand kit.

The canonical supplied kit is `design/brand-kit/`; the original archive is `design/source/VoltoShare_Brand_Kit.zip`. Preserve those originals. The proposal and open commercial decisions are in `docs/PROJECT_BRIEF.md`. The kit's demo/code files are references, not authorization to replace the live sites or activate real integrations.

## Current delivery boundary

Both public URLs currently serve blank placeholders. Receipt of this kit and creation of the design skill do not authorize building or publishing the full reference demo. Implement the actual website/app when Mathis asks; consult `docs/DEPLOYMENT.md` for existing routes and services. Keep source PDFs, the ZIP and private data outside the public site roots.
